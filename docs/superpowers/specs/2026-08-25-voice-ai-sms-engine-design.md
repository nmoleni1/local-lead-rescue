# Phase 1 Design Spec: 2-Way Voice AI & SMS Lead Rescue Engine

**Date**: 2026-08-25  
**Topic**: Voice AI Receptionist, 2-Way SMS Routing & Missed-Call Recovery  
**Target Market**: Local Trade Contractors in West Valley City, UT  

---

## 1. Executive Summary & Problem
Local contractors (plumbers, HVAC, electricians) miss 40–60% of incoming phone calls when working in the field. Unanswered callers hang up and immediately dial a competitor on Google. Small trade businesses lack dispatch staff and rarely maintain digital calendars. 

**LeadRescue AI Phase 1** delivers a zero-friction, automated 2-way Voice AI Receptionist and Missed-Call Auto-Text (MCAT) engine that qualifies callers, captures job details & dispatch windows, logs leads into Supabase PostgreSQL, and sends 1-tap mobile action alerts to contractor cell phones.

## 3. Core Functional Requirements

### 3.1 AI Voice Receptionist (`/api/voice/inbound`)
- Answers on 1st ring with high-quality TwiML voice synthesis (friendly, professional tone).
- Gathers:
  1. Caller Name
  2. Issue / Service Type (e.g. leaking water heater, AC failure)
  3. Street Address / Neighborhood (e.g. 3500 S West Valley)
  4. Urgency & Preferred Window (*Morning 8-12 / Afternoon 12-4 / Emergency ASAP*)
- Reassures caller that dispatch ticket is created and contractor will confirm shortly.

### 3.2 Missed-Call Auto-Text Fallback (`/api/voice/status` & `/api/webhook/lead`)
- If caller drops or line is busy, system triggers instant SMS (<15 seconds):
  > *"Hey! This is Mike with [Company]. I'm on a job site and missed your call. How can I help you today?"*

### 3.3 2-Way SMS Threading (`/api/sms/inbound`)
- When homeowner replies via SMS:
  - Appends message to Supabase `messages` table.
  - Sends instant Contractor SMS Push:
    > *"🚨 Lead Alert from 801-xxx: 'Water leak in basement at 4200 S'. Tap to Call: tel:801xxxxxxx"*

### 3.4 Flexible Arrival Windows (Zero-Calendar Friction)
- Default windows:
  - `Emergency ASAP` (2–4 hour target)
  - `Morning Window` (8:00 AM – 12:00 PM)
  - `Afternoon Window` (12:00 PM – 4:00 PM)
  - `Next Day / Flexible`
- No complex calendar integration required for contractor.

## 4. Database Schema (Supabase PostgreSQL)

```sql
-- 1. Calls Table
CREATE TABLE IF NOT EXISTS calls (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    call_sid TEXT UNIQUE,
    from_number TEXT NOT NULL,
    to_number TEXT NOT NULL,
    duration INTEGER DEFAULT 0,
    transcript TEXT,
    recording_url TEXT,
    status TEXT DEFAULT 'completed',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. 2-Way Messages Table
CREATE TABLE IF NOT EXISTS messages (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    lead_id BIGINT REFERENCES leads(id) ON DELETE CASCADE,
    from_number TEXT NOT NULL,
    to_number TEXT NOT NULL,
    direction TEXT CHECK (direction IN ('inbound', 'outbound')),
    body TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 3. Lead Schema Enhancements
ALTER TABLE leads ADD COLUMN IF NOT EXISTS address TEXT;
ALTER TABLE leads ADD COLUMN IF NOT EXISTS preferred_window TEXT;
ALTER TABLE leads ADD COLUMN IF NOT EXISTS call_sid TEXT;
```

## 5. API Endpoints (`api/index.py`)

| Endpoint | Method | Purpose |
| :--- | :--- | :--- |
| `/api/voice/inbound` | `POST` | Serves TwiML conversational voice prompts & speech recognition. |
| `/api/voice/gather` | `POST` | Processes caller speech input, transcribes, extracts lead fields, creates ticket. |
| `/api/voice/status` | `POST` | Webhook for call completion/drop & missed call SMS trigger. |
| `/api/sms/inbound` | `POST` | Webhook for incoming customer SMS replies & contractor alert dispatch. |
| `/api/leads` | `GET` | Returns leads with call transcripts, arrival windows, and message threads. |
| `/api/sms/send` | `POST` | Contractor manual SMS dispatch from web dashboard. |
